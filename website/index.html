Install in 60 seconds (and why SmartScreen appears)

Transparent instructions so you know exactly what you are running on Windows.

1. Download & Extract

Grab IMAGEX-Windows.zip from GitHub Releases and extract the folder anywhere on your PC.

2. Run IMAGEX.exe

Because independent builds do not buy an expensive corporate signing certificate yet, Windows SmartScreen may show a warning. Click "More info" -> "Run anyway", or verify the public CI workflow that built the binary.

View GitHub Actions Build Logs ->

3. Optional Python / Chromium

Prefer running from source, or need full browser-backed extraction? Run python -m playwright install chromium and python -m src.main directly from the repo.
