# IMAGEX v5.8.1

## Português

- O executável do Windows pode carregar conectores padrão preparados para distribuição. Sem um pacote padrão, a descoberta automática continua disponível ao colar um link.
- A descoberta pode usar um link direto público quando o site não oferece uma página inicial.
- A configuração local continua editável e tem precedência sobre um conector padrão com o mesmo identificador.

## English

- The Windows executable can load distributable default connectors. Where none are bundled, link-based discovery is still available.
- Discovery can use a public deep link when the website does not offer a home page.
- Local configuration remains editable and takes precedence over a bundled connector with the same ID.
