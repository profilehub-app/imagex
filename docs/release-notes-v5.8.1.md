# IMAGEX v5.8.1

## Português

- O executável do Windows pode carregar conectores padrão empacotados sem exigir um arquivo de configuração local.
- A configuração local continua editável e tem precedência sobre um conector padrão com o mesmo identificador.

## English

- The Windows executable can load bundled default connectors without requiring a local configuration file.
- Local configuration remains editable and takes precedence over a bundled connector with the same ID.
